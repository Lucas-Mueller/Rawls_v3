# Letter-Based Legacy Archive

**⚠️ WARNING: HISTORICAL FILES ONLY - DO NOT USE IN ACTIVE SYSTEM ⚠️**

This archive contains historical files from the Frohlich Experiment system that used letter-based principle references ("principle a", "principle b", etc.). These files are preserved for historical reference but **MUST NOT** be used in the active system.

## Archive Structure

- `english/` - English language letter-based legacy files
- `spanish/` - Spanish language letter-based legacy files  
- `mandarin/` - Mandarin language letter-based legacy files

## Historical Context

The Frohlich Experiment system originally used letter-based references (a, b, c, d) to refer to the four justice principles. This approach was completely removed in August 2025 to ensure proper principle identification and eliminate parsing ambiguities.

### The Four Justice Principles (Current Full Names Only)
1. **Maximizing the floor income** - Maximizes the lowest income in society
2. **Maximizing the average income** - Maximizes the average income in society
3. **Maximizing the average income with a floor constraint** - Maximizes average while ensuring minimum income
4. **Maximizing the average income with a range constraint** - Maximizes average while limiting income gap

## Why These Files Are Archived

Letter-based references caused critical system issues:
- Parsing ambiguities and false positives
- Cross-language inconsistencies
- Agent confusion in principle identification
- Test failures and validation problems

## For Researchers

If you need to understand the system's evolution or compare historical vs. current approaches, these files provide context. However, **never integrate any content from these files into the active system**.
